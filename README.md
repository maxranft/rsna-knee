# rsna-knee
Machine learning model to grade MRI scans over a variety of knee injuries. 
1. ACL 
2. MCL 
3. Medial Meniscus 
4. Lateral Meniscus 
5. Medial OA 
6. Lateral OA 
7. PF OA 
8. Effusion 
9. Synovitis
10. Bakers Cyst 
11. Contusions 
12. Fractures 

Kaggle **RSNA Knee Abnormality Detection** (2026): predict 12 knee-MRI findings per study, scored by macro AUC. Graded  based upon accuracy, and efficancy. 

**Status:** competition closed 2026-10-22. Final score: public 0.796, private 0.783. What worked, what didn't and why: [docs/postmortem.md](docs/postmortem.md).
