FUNCTIONS USED BY THE COMMANDS (rsna-knee)
Companion to start/training_commands.txt: every Python function each command there runs.
Left out: shell-only steps (pgrep, pkill, caffeinate, pmset, open, tail), which have no functions, and the
JavaScript inside the dashboard page and the grading page.


1. WHICH COMMAND RUNS WHAT
--------------------------
start/1_review_tool.command          -> scripts/review.py                                        (section 5)
start/2_results_dashboard.command    -> scripts/dashboard.py --open                              (section 4)
start/5_graphs.command               -> scripts/graphs.py --open (which runs scripts/dashboard.py --quiet first) (section 4)
start/3_run_training.command         -> load_state() from scripts/auto_improve.py for the config, then
                                        scripts/train_head.py once per seed, then scripts/watch_training.sh;
                                        with LID_CLOSED=1 also scripts/keep_awake.sh       (sections 2 and 4)
start/4_run_external.command             -> scripts/keep_awake.sh, scripts/dashboard.py --open, scripts/external_study.py,
                                        scripts/review.py --external                    (sections 4 and 6)
scripts/auto_improve.py              -> scripts/train_head.py once per seed (as a separate process)
scripts/train_head.py                -> scripts/dashboard.py --quiet after every fold and at the end
scripts/watch_training.sh, scripts/keep_awake.sh -> shell only; no functions


2. TRAINING: scripts/train_head.py
----------------------------------
scripts/train_head.py
  main()                 read the options; build the targets (gold labels for the 58 gold studies, report scores for
                         the rest, mixed with the teacher when --teacher is set); train one head per fold; write
                         oof.csv, metrics.json, config.json and head_fold*.pt; add the row to experiments.md
  evaluate()             predictions and mean loss of a model on the validation fold
  aucs()                 AUC per label for a set of studies (skips a label with only one class)
  accs()                 accuracy per label at the 0.5 threshold for a set of studies (shown on the dashboard; AUC
                         decides)
  refresh_dashboard()    rebuild runs/dashboard.html in the background; can never stop training
  (at the end it also prints analysis_text() from src/knee/dashboard.py: see section 4)

src/knee/head.py  (the model and its data)
  Head.__init__()        build the head: slice projection, slot and depth embeddings, transformer, one attention
                         query per label
  Head.forward()         all slices of a study -> 12 scores (logits)
  fourier()              turn a slice's position in its series into sine and cosine features
  Studies.__init__()     dataset of studies: which cached slices belong to each study, and its targets
  Studies.feats          open the feature files, once per worker
  Studies.__len__()      number of studies
  Studies.__getitem__()  one study's slice tokens, slot ids, depths and targets; in training it randomly drops
                         a series slot (and slices, with --slice-drop)
  collate()              pad the studies of a batch to the same length
  mirror()               lay a left knee out like a right knee; only runs with --canon, which no listed command passes

src/knee/progress.py  (history.jsonl and progress.png)
  ProgressTracker.__init__()   start history.jsonl and progress.png for the run
  ProgressTracker.log()        record one epoch, redraw the picture, print the "fold 0 epoch 1/28 ..." line
  ProgressTracker.finish()     add the final gold and report AUC to the picture
  ProgressTracker.render()     draw the four panels and save the picture
  ProgressTracker._fold_hist() the epochs recorded for one fold
  ProgressTracker._best()      the best epoch of a fold so far
  ProgressTracker._eta()       time left, from the average epoch so far
  ProgressTracker._greeks()    delta and gamma of the fold so far, for the epoch line
  ProgressTracker._style()     shared look of a panel
  ProgressTracker._curves()    loss and validation AUC curves
  ProgressTracker._bars()      AUC per label at the latest epoch
  ProgressTracker._status()    the text panel (progress, best epoch, final scores)


3. THE AUTO-IMPROVE LOOP: scripts/auto_improve.py
-------------------------------------------------
--plan uses main, load_state, describe, seed_cliff. --add uses main, load_state. --until uses all of them.

scripts/auto_improve.py
  main()            read the options; print the base config and every verdict; run what is pending
  load_state()      read runs/auto/queue.json and state.json (creates them the first time)
  save_state()      write state.json
  describe()        say a change in words, e.g. "epochs 28 (was 20)"
  run_candidate()   train 3 seeds of one change, judge it, write the verdict, adopt it if it passed
  train()           run train_head.py for one seed, or reuse the finished run
  find_run()        find a finished run by its --log text
  judge()           compare two 3-run ensembles on report and gold labels (paired bootstrap) and apply the rule
  seed_cliff()      Cliff's delta between the candidate's seeds and the base's seeds, for report and gold
  note_verdict()    write Adopted / Rejected into the Notes column of experiments.md
  fill_seeds()      after the candidates, train extra seeds of the base config

src/knee/dashboard.py  (statistics shared with the dashboard)
  truth()           fold table, gold labels and report labels (train.csv is read without its Report column)
  boot_diff()       difference in macro AUC between two sets of predictions, with a 90% interval
  macro()           macro AUC over the 12 labels
  auc()             AUC of one label
  cliff()           Cliff's delta: share of pairs won minus share of pairs lost


4. THE DASHBOARD: scripts/dashboard.py
--------------------------------------
scripts/dashboard.py
  main()            read the options; build once, open it with --open, rebuild on a timer with --watch
  build_locked()    build unless another build is already running

src/knee/dashboard.py
  build()               collect everything, put it into the page template, write runs/dashboard.html
  collect()             pick the reference run and gather every section
  clean()               make the numbers safe to store as JSON
  verdicts()            read Adopted / Rejected / Current reference from experiments.md
  runs_section()        one row per run: scores, difference from the reference, learning curve, progress, accuracy
                        and the path for the 3D view
  read_cache()          a run's dash_cache.json (the slow results kept between builds); an unreadable one is rebuilt
  head_params()         number of weights in a run's head
  compact_history()     validation AUC per epoch, per fold
  greeks()              a run's learning-curve delta (AUC gained per epoch) and gamma (change in delta), and the
                        epoch from which it is flat
  path3d()              a run's path for the 3D view: per epoch the validation AUC and accuracy (mean over the
                        folds that reached it) with that epoch's delta and gamma
  macro_acc()           accuracy at the 0.5 threshold of a run's out-of-fold predictions against the report labels
                        (report-only studies, mean over the 12 labels), for runs from before train_head.py stored it
  stored_acc()          a finished run's stored accuracy (metrics.json, else the dashboard cache), for analysis_text()
  config_groups()       group runs into configs (same settings, different seeds)
  config_of()           the settings that define a config (everything except the seed)
  best_group()          the current best config (the auto-improve base)
  configs_section()     compare every config with the current best, seed by seed; differs() inside it words how
                        a config differs from the best
  boot_cliff()          Cliff's delta with a 90% interval
  welch()               Welch's 90% interval for the difference between two configs' mean AUC (the forest plot)
  differs()             word how a config differs from the current best
  betas_section()       betas across configs: each label against the other labels (report), and gold against
                        report for each label and for the macro
  beta(), boot_beta()   beta = covariance / variance (how much one score moves when another moves by 1), and
                        the same with a 90% interval
  same_labels()         the configs trained on the current best config's labels (betas_section and plane_section)
  plane_section()       the 3D view's plane across configs: accuracy = alpha + beta_auc * report AUC + beta_time *
                        training minutes, by least squares, with r2 and a 90% interval for both betas
  train_minutes()       a run's training minutes with the pauses taken out (median epoch time x epochs trained)
  cliff(), boot_diff(), macro(), auc(), truth()   as in section 3
  reference_section()   the reference model per label: AUC with intervals, ROC curves, right vs left knee
  boot_labels()         AUC per label with a 90% interval
  data_section()        counts of studies, slices, folds, label prevalence, scanners, knee side, feature caches
  normalise_vendor()    tidy the scanner maker's name
  efficiency_section()  estimated runtime of a submission
  analysis_text()       one run's statistical analysis as text for the terminal: its seeds, accuracy, Cliff's delta
                        against the current best, delta and gamma, betas and per-label scores

scripts/graphs.py  (every chart on its own: graphs/*.png and the graphs window, runs/dashboard.html?graphs)
  main()            read the options; rebuild the dashboard, save the PNGs, open the window with --open
  save()            open runs/dashboard.html?graphs&export in headless Chrome and save each chart card as
                    graphs/NN-<chart>[-<view>].png (every view of the 3D chart and the heat map), plus graphs/README.md
  Chrome            headless Google Chrome driven over the DevTools protocol on a pipe: call(), wait(), js(), png(),
                    close()
  open_window()     the graphs page in a Chrome app window (no tabs or address bar)

src/knee/results.py
  load_runs()           one row per run in runs/, from args.json, metrics.json and history.jsonl
  _json(), _history()   read one run's files


5. THE GRADING TOOL: start/1_review_tool.command -> scripts/review.py
---------------------------------------------------------------------
scripts/review.py
  main()                    read the options, pick the run, start the local web server, open the browser
  latest_run()              the newest finished run
  make_handler()            build the web request handler H around the app
  H.do_GET()                answer the page's requests: the page itself, the queue, an item, its maps, an image
  H.do_POST()               take a decision or a change of queue from the page
  H.send()                  send a reply
  H.log_message()           keep the server quiet
  App.__init__()            the grading session
  App.load_queue()          build the queue for a mode and finding
  App.session()             the queue and what has been decided so far
  App.tally()               counts of the decisions
  App.item()                everything shown for one item: probability, labels, slice evidence, summary, report
  App.region()              the coarse 4x4 evidence map of one slice
  App.fine()                the finer 8x8 evidence map of one slice
  App.image()               one slice as a PNG
  App.decide()              record a decision in meta/reviews.csv with what it implies
  RealSource.__init__()     load the run: config, out-of-fold predictions, report scores
  RealSource.queue()        the (study, finding) items to grade, without the ones already graded
  RealSource.model()        load the head of one fold
  RealSource.tokens()       load one study's cached features
  RealSource.explain()      how much each slice moved the score (leave one slice out)
  RealSource.region()       how much each of the 16 regions of a slice moved the score
  RealSource.fine_region()  the same for 8x8 image blocks, by re-encoding the slice
  RealSource.encoder()      the frozen encoder on the CPU, plus the run's PCA
  RealSource.report()       the report's sentences, in English when a translation exists
  RealSource.translations() reload the translations when the file changes
  RealSource.fetch_translations()   download the translations from Kaggle in the background (go() inside it)
  RealSource.stack()        one study's images
  RealSource.ready()        how many of the queue's image stacks are downloaded
  StackFetcher.__init__(), StackFetcher.run()   download the image stacks from Kaggle in the background
  verdict()                 probability -> present or absent (0.5)
  consequences()            what Accept and Deny each say about the truth, the model and the label
  summarise()               plain-English account of which slices carried the call
  split_sentences()         split a report into sentences
  report_view()             mark the sentences that mention the finding
  to_png()                  an array as PNG bytes
  read_reviews()            read meta/reviews.csv
  stack_path()              where a study's image stack is stored

src/knee/head.py:      Head.from_config(), Head.forward(), fourier(), Studies (as in section 2)
src/knee/features.py:  load_encoder() loads the frozen DINOv2 encoder; encode() turns slices into tokens

scripts/external_graphs.py  (the three graphs opened in Preview)
  write_graphs()             draw and save the three graphs
  load()                     read the results written by external_study.py
  scores_vs_training()       graph 1: this knee's scores against the training knees
  where_the_model_looked()   graph 2: evidence across the slices of every series
  strongest_slices()         graph 3: the slice with the strongest evidence for each finding
  header(), source_note(), ordinal(), truth_colour(), truth_word()   titles, notes and colours

scripts/review.py  (its grading window, port 8766; main, make_handler, H.*, App.* and the helpers as in section 5)
  ExternalSource.__init__()  load the scan's results and the truth filled in from the radiologist's report
  ExternalSource.queue()     the 12 findings, most unusual first
  ExternalSource.explain()   the stored slice evidence for a finding
  ExternalSource.model(), .tokens(), .encoder(), .stack(), .report(), .ready()   hand the tool the scan's data
  MeanHead.__init__(), MeanHead.forward()   several heads as one model: their mean score

src/knee/preprocess.py: choose_series() picks the series per slot; load_volume() reads a series into a volume;
                        _to_grid() resamples it to the training grid; to_uint8() scales it to 0-255
src/knee/features.py:   load_encoder(), encode() (as in section 5)
src/knee/head.py:       Head.from_config(), Head.forward(), fourier()
